# Repository Layout

이 문서는 레포지토리의 주요 4-Pillar 구조(Agentic OS)를 설명합니다.

| 분류 | 역할 | 용도 | 특징 |
|---|---|---|---|
| **system/** | [뼈대] AI 구동 인프라 및 환경 설정 | 전역 설정, 훅(Hooks), 서브에이전트, MCP 설정 | 코드·스크립트 중심 |
| **brain/** | [지능] AI의 판단 기준 (법전) | 코딩 스탠다드, 기획 원칙, 프로세스 | AI를 위한 마크다운 |
| **skills/** | [행동] 슬래시 커맨드 트리거 | `/review:all`, `/plan:ideation` 등의 커맨드 진입점 | 사람이 호출함 |
| **docs/** | [설명서] 인간용 매뉴얼 | 레포지토리 구조, 로컬 환경 셋업, 가이드 | 사람을 위한 마크다운 |
