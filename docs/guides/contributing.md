# Contributing Guide

`claude-cockpit`에 기여해 주셔서 감사합니다! 
당신이 만든 멋진 프롬프트 엔지니어링 팁이나 슬래시 커맨드를 전 세계 개발자들과 나누는 방법을 안내합니다.

## 새로운 스킬(Slash Command) 추가하기

### 1. 스킬 파일 작성
당신이 한국어 화자라면, `skills/` 하위의 적절한 카테고리(예: `dev/`)에 `*.ko.md` 확장자로 스킬을 작성하세요.
*   예시: `skills/dev/my-new-skill.ko.md`
*   반드시 다른 스킬 파일들의 템플릿(YAML Frontmatter 등) 형식을 지켜주세요.

### 2. (선택 사항) 코어 룰셋(Standards) 작성
만약 당신의 스킬이 완전히 새로운 개념(예: 새로운 보안 점검 프레임워크)을 도입한다면, 지식을 스킬 파일에 다 적지 말고 `brain/` 아래에 독립적인 규칙 파일로 분리하세요.
*   예: `brain/engineering/security-check.md`

### 3. 다국어(I18n) 동기화
글로벌 기여를 위해 영어 버전은 필수입니다! 하지만 직접 번역할 필요는 없습니다.
터미널에서 아래 스크립트를 실행하면 AI가 당신의 `.ko.md` 파일을 영어 원본(`.md`)으로 아름답게 자동 번역해 줍니다.

```bash
./scripts/sync-i18n.sh
```
*주의: 이 스크립트를 실행하려면 `claude` 커맨드라인 도구가 설치되어 있어야 합니다.*

### 4. Pull Request 제출
번역된 `.md` 파일과 원본 `.ko.md` 파일을 모두 커밋하여 PR을 올려주세요.
우리의 리뷰어 에이전트(`/review:cockpit`)가 룰셋 포맷팅을 검토한 후 머지될 것입니다.
