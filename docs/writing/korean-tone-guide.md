# 한글 톤 가이드

> 대상: Claude 응답, 문서, 커밋 메시지, PR 설명. 영어 식별자는 그대로 유지.

## 핵심 규칙

1. **모든 응답은 존댓말**로 작성합니다 ("합니다", "하세요", "드리겠습니다").
2. **코드 변수·함수·파일명은 영어**. 주석과 설명은 한글.
3. **간결하게**. 리뷰어는 시간이 없습니다.

## 존댓말 사용 범위

| 맥락 | 톤 | 예 |
|------|----|----|
| 사용자 응답 | 존댓말 | "확인했습니다. 반영하겠습니다." |
| 문서 본문 | 존댓말 (해요체/합쇼체) | "이 설정을 따라야 합니다." |
| 커밋 메시지 제목 | 명령형/명사형 | "add: Keychain 저장소 도입" |
| 커밋 메시지 본문 | 존댓말 또는 중립 | "…이유로 변경했습니다." |
| PR 설명 | 존댓말 | "~을 추가했습니다." |
| 코드 주석 | 중립 (단정형) | "// 만료 시 재발급" |

## 어미 통일

- 해요체 혼용 피하기. 한 문서 안에서 "합니다/하세요"로 통일하세요.
- "~입니다" 반복은 단조로우므로 "~합니다", "~됩니다" 와 교차.

## 영어·한글 혼용

- 기술 용어는 **영어 원문 유지**: "심볼릭 링크", "프로미스", "캐시", "서브모듈"
- 한국어 관용 표기가 더 명확하면 한글: "배열", "문자열", "객체"
- 고유명사 공식 표기: `claude-cockpit`, `Claude Code`, `Anthropic`

## 띄어쓰기·문장부호

- 긴 문장은 쉼표로 끊지 말고 **마침표로 분리**
- 마침표는 문장 끝에만. 제목·리스트 항목은 마침표 없음
- `·` (가운뎃점) 은 병렬 나열에 사용: "GitHub · Jira · Confluence"
- `/` 는 동일 계층 선택지: "코드/문서", "단위 테스트/통합 테스트"

## 금지 표현

- 과장: "매우 중요", "정말 필수", "아주 빠름" → 수치·조건으로 대체
- 모호함: "적절히", "필요하면", "가능하면" → 구체적 기준 명시
- 불필요한 영어 혼용: "해당 이슈를 resolve 해주세요" → "해당 이슈를 해결해 주세요"
- 반말·구어체: "~해야돼", "~하자" → 문서에서는 쓰지 않음

## AI 응답 특유 주의

- **불필요한 서론 금지**: "네, 확인했습니다. 지금부터 ~~을 시작하겠습니다" 같은 반복적 확인 제거
- **마무리 요약 금지**: 사용자가 이미 diff 를 볼 수 있다면 "~~을 완료했습니다"만 있으면 충분
- **이모지 자제**: 사용자가 명시적으로 요청하지 않으면 사용하지 않음

## 체크리스트

- [ ] 모든 문장이 존댓말인가
- [ ] 한 문장이 두 줄을 넘지 않는가
- [ ] 과장·모호한 표현이 없는가
- [ ] 영어 식별자와 한글 설명이 명확히 분리되어 있는가
