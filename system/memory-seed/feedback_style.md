- **잡담·과도한 요약 금지** — "방금 이런 걸 했어요" 식 요약은 diff 로 충분.

## 작업 방식

- **파일 먼저, 빌드 나중** — 여러 파일은 한 번에 작성하고 마지막에 한 번만 빌드.
  **Why**: 한 개씩 고치고 빌드 반복하면 컨텍스트 낭비.
  **How to apply**: 배치로 모으고, 실패 시 에러 전체 확인 후 일괄 수정.

- **기존 패턴 먼저 확인** — 코드 작성 전 같은 디렉토리 파일 1-2개 먼저 읽기.
  **Why**: 스타일·import·생성자 패턴 일치를 위해.
  **How to apply**: 새 파일 생성 직전에 Read 로 이웃 확인.
