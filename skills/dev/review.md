# 프로젝트 리뷰

> ⚠️ **Standards 준수 필수** — 리뷰 판단 기준은 아래 문서를 우선합니다.
> @standards/CLAUDE.md · @standards/coding/coding-guidelines.md · @standards/testing/testing-guidelines.md

프로젝트의 품질을 종합 분석합니다. 기본은 요약 모드, `deep`을 붙이면 심층 모드로 실행합니다.

$ARGUMENTS
- `deep` — 심층 모드 (코드 예시 + 개선 코드 포함)
- **서비스명 또는 경로** — 해당 범위만 분석
- 인자 없음 → 프로젝트 전체를 요약 모드로 분석
- 예: `/dev:review`, `/dev:review account`, `/dev:review deep platform/account`

## Step 0: 프로젝트 컨텍스트 파악

분석 전에 아래를 먼저 파악합니다:
- 프로젝트의 언어, 프레임워크, 빌드 도구
- CLAUDE.md 및 가이드라인 문서 경로 (특히 `docs/standards/` 또는 `@standards/*`)
- 디렉토리 구조 및 아키텍처 패턴

이 정보를 **모든 에이전트 프롬프트에 한 줄 요약으로 포함**합니다.

## Step 1: 모드 판별

$ARGUMENTS에 `deep`이 포함되어 있으면 **심층 모드**, 아니면 **요약 모드**로 실행합니다.

## Step 2: 병렬 분석 (5개 에이전트 동시 실행)

아래 5개 영역을 **반드시 하나의 메시지에서 5개 Agent tool을 동시에 호출**합니다.

| # | 영역 | Agent subagent_type | 분석 내용 |
|---|------|---------------------|----------|
| 1 | 아키텍처 | `code-review-ai:architect-review` | 아키텍처 패턴, 의존성 방향, 계층 분리, DDD 적용 수준 |
| 2 | 코드 품질 | `pr-review-toolkit:code-reviewer` | SOLID 원칙, 안티패턴, 코딩 스타일, standards 준수 |
| 3 | 테스트 | `pr-review-toolkit:pr-test-analyzer` | 테스트 구조, 커버리지, 엣지케이스, 테스트 피라미드 |
| 4 | 보안 | `pr-review-toolkit:silent-failure-hunter` | 조용한 실패, 에러 핸들링 누락, 인증/인가, OWASP Top 10 |
| 5 | 의존성 | `backend-development:backend-architect` | 취약 버전, 라이선스 호환성, 업데이트 필요성 |

### 에이전트 속도 규칙

- **빌드/테스트 실행 금지** — 코드를 읽고 분석만 수행
- **결과는 1000자 이내**로 반환 — 점수 + 강점 + 문제만 포함
- 5개 모두 서로 다른 전문 에이전트 사용

### 에이전트 프롬프트

각 에이전트에게 다음을 전달합니다:
- Step 0에서 파악한 프로젝트 컨텍스트 (한 줄)
- 분석 대상 경로
- standards 문서 경로 (`docs/standards/*` 또는 cockpit의 `@standards/*`)
- 아래 모드별 출력 지시

**요약 모드 지시:**
```
출력 형식 (이 형식만 반환, 다른 설명 금지):
- 점수: X/100
- 강점: [2-3개, 한 줄씩]
- 문제: [최대 3개, 각각 파일경로:줄번호 + 한 줄 설명]
```

**심층 모드 지시:**
```
출력 형식 (이 형식만 반환, 다른 설명 금지):
- 점수: X/100
- 강점: [2-3개, 한 줄씩]
- 문제: [최대 5개, 각각 아래 형식으로]
  > *파일: [경로:줄번호]*
  > *코드:* [문제 코드 블록]
  > *문제:* [설명] → *개선:* [개선 코드 또는 방향]
```

### 분석 깊이 가이드
- 소규모 (파일 30개 이하): 전체 파일 분석
- 중규모 (파일 30~100개): 핵심 도메인/비즈니스 로직 전체 + 인프라/설정 코드 샘플링
- 대규모 (파일 100개 초과): 디렉토리 구조 전체 파악 후, 모듈별 대표 파일 중심 심층 분석

## Step 3: 보고서 출력

5개 에이전트 결과를 수집한 뒤 아래 형식으로 **직접** 작성합니다. 취합 에이전트를 추가로 실행하지 않습니다.

```markdown
# 프로젝트 리뷰 결과

**프로젝트**: [이름] | **범위**: [경로] | **스택**: [언어/FW] | **모드**: 요약/심층
```
